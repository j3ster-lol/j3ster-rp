# J3STER // ROLEPLAY

Moderní československý roleplay projekt zaměřený na kvalitní RP, aktivní komunitu a propracovaný herní systém.

## O projektu

J3STER // ROLEPLAY je CZ/SK roleplay projekt, kde se snažíme vytvořit prostředí pro hráče, kteří hledají kvalitní, přehledné a aktivní RP.

Projekt se zaměřuje především na:

* kvalitní roleplay
* aktivní komunitu
* propracované frakce
* pravidelné eventy
* férový A-Team
* vlastní systémy a funkce
* moderní web a Discord

## Web

Tento repozitář obsahuje zdrojové soubory oficiálního webu J3STER // ROLEPLAY.
